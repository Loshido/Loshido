GET /ws

Passer sur le protocole Websocket.

Ici vous pouvez passer sur le protocole Websocket, vous pouvez envoyer trois types de messages en utilisant ce protocole. 

{
    "type": "Launch",
    "name": string,
    "color": [number, number, number],
    "citation": string
}
{
    "type": "Update",
    "name": string, // optionel
    "color": [number, number, number], // optionel
}
{
    "type": "Signal",
    "position": [number, number, number],
    "rotation": [number, number, number]
}
